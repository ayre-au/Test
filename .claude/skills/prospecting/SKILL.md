# Prospecting

Read `CLAUDE.md`, `playbook/PLAYBOOK.md` §8–9 and `playbook/DIALOGUES.md` C first.

- **Priority order:**
  1. Expired and withdrawn listings
  2. Past appraisals from the last 12–18 months
  3. Hot pipeline
  4. Past vendors
  5. Buyers who own a home
- **Expired script:** "What would need to be different for you to consider selling again?"
- **10-week target:** work backwards from the GCI or market-share goal to listings, appraisals, conversations and calls per day. Show the maths.
- **Morning prospecting is protected time,** so schedule it first.
- If a daily listed/sold/under-contract/withdrawn feed is available, use it to build the expired and withdrawn list.
- Output a call list table: name, reason, script line, outcome column.
